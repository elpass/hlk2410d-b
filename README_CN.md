# HLK-LD2410D-B Home Assistant 自定义集成

## 一、 简介

**HLK-LD2410D-B** 是海凌科（Hi-Link）推出的一款 24GHz 毫米波静止人体存在感应雷达模块（蓝牙版）。它采用 FMCW 调频连续波技术，结合智能算法，能够精准识别运动、微动及完全静止状态下的人体，最远探测距离达 10 米，覆盖角度 ±60°，支持挂顶与挂壁安装。

本自定义集成通过 **蓝牙 BLE 直连** 的方式，将该雷达模块无缝接入 Home Assistant，实现实时距离监测、远程参数配置和设备管理，无需额外的串口网关或 ESPHome 中转设备。

---

## 二、 核心功能特性

| 功能 | 说明 |
| :--- | :--- |
| **实时目标距离监测** | 通过蓝牙实时接收雷达上报的目标距离数据（单位：厘米） |
| **远程参数配置** | 支持在 HA 前端直接修改最大检测距离、目标延迟、灵敏度等核心参数 |
| **自动门限生成** | 支持远程触发模块的自动门限生成功能，适应新安装环境 |
| **可视化进度反馈** | 所有配置操作（读取/设置/重启）均提供实时进度百分比显示 |
| **深度适配自动化** | 距离传感器采用整型数值输出，特殊状态使用特征值，完美适配 HA 数值条件判断 |
| **安全重启机制** | 针对模块重启断连特性，设计了"发送→倒计时→自动重连"的完整重启流程 |

## 三、 安装与配置

### 3.1 安装前提
- Home Assistant 版本 ≥ 2024.x
- HA 主机具备蓝牙功能（内置蓝牙或 USB 蓝牙适配器）
- 已安装 **Bluetooth** 集成并正常运行
- 推荐使用 ESP32蓝牙代理 更稳定 (ESP32 C3 SUPER MINI PRO)

### 3.2 安装方式

**手动安装：**
1. 将 `hlk2410d_b` 文件夹复制到 HA 的 `custom_components/` 目录下
2. 确保目录结构如下：
   ```
   custom_components/hlk2410d_b/
   ├── __init__.py
   ├── manifest.json
   ├── const.py
   ├── ble_manager.py
   ├── coordinator.py
   ├── protocol.py
   ├── entity.py
   ├── config_flow.py
   ├── sensor.py
   ├── number.py
   └── button.py
   ```
3. 重启 Home Assistant

### 3.3 添加设备
1. 进入 **设置 → 设备与服务 → 添加集成**
2. 搜索 **HLK-LD2410D-B**
3. 选择扫描到的雷达设备（名称通常为 `HLK-LD2410D-B` 或类似）
4. 完成配对，设备将自动添加到 HA

## 四、 实体说明

集成添加成功后，会自动创建以下实体：

### 4.1 传感器（Sensor）

| 实体名称 | 类型 | 说明 |
| :--- | :--- | :--- |
| **目标距离** | `sensor` | 核心传感器，返回整型数值（单位：cm）。详见下方数值定义表。 |
| **诊断** | `sensor` | 显示当前工作模式和操作进度，如"正常模式"或"配置模式 50%"。 |

#### 📏 目标距离数值定义

| 返回值 | 含义 | 场景 |
| :---: | :--- | :--- |
| `1 ~ 1000` | 实际目标距离（厘米） | 正常模式下检测到人体 |
| `2026` | 无目标 | 正常模式下未检测到人体 |
| `0` | 配置模式 | 模块处于参数配置/重启流程中，暂停距离上报 |

> **设计说明**：使用 `2026` 代表无目标（而非 0 或 null），是为了在 HA 自动化中可以统一使用 `numeric_state` 进行数值比较，避免字符串判断的复杂性。

### 4.2 数值输入（Number）

| 实体名称 | 范围 | 说明 |
| :--- | :--- | :--- |
| **最大距离** | 0.5 ~ 10.0 m | 雷达的最大检测距离，步进 0.1m |
| **目标延迟** | 0 ~ 100 s | 目标消失后延迟多久才判定为"无人" |
| **灵敏度** | 1 ~ 5 | 检测灵敏度等级，1 最低，5 最高 |
| **门限系数** | 0 ~ 4 | 自动门限生成的环境系数索引 |

> ⚠️ **注意**：修改上述数值后，数值仅保存在 HA 本地。必须点击 **"设置"** 按钮才能将参数写入雷达模块。

### 4.3 按钮（Button）

| 实体名称 | 图标 | 功能 |
| :--- | :--- | :--- |
| **读取** | `mdi:download` | 从雷达模块读取当前参数并同步到 HA |
| **设置** | `mdi:upload` | 将 HA 中修改的参数写入雷达模块并保存 |
| **重启** | `mdi:restart` | 重启雷达模块（包含自动重连流程） |

## 五、 操作指南

### 5.1 首次使用：读取参数

新安装或重置后，建议先读取模块的出厂/已有参数：

1. 确保蓝牙连接正常（诊断传感器显示"正常模式"）
2. 点击 **"读取"** 按钮
3. 观察 **诊断** 传感器的进度变化：`10% → 30% → 60% → 90% → 100%`
4. 进度完成后，各数值输入实体会自动更新为模块当前值

### 5.2 修改参数：设置流程

1. 在数值输入实体中调整所需参数（如将最大距离改为 5.0m）
2. 点击 **"设置"** 按钮
3. 诊断传感器会显示配置进度，仅修改的参数会被写入
4. 完成后自动退出配置模式，恢复正常距离监测

### 5.3 重启模块

当需要重启模块（如应用某些底层配置或排除异常）时：

1. 点击 **"重启"** 按钮
2. 流程说明：
   - `10%`：进入配置模式
   - `20%`：发送重启指令（此时模块开始重启，蓝牙断连）
   - `30% ~ 100%`：倒计时等待模块启动（每秒增加 10%）
   - `100%` 后：自动重新连接蓝牙，恢复正常模式
3. 整个过程约 8~10 秒，期间目标距离显示为 `0`

## 六、 自动化与场景应用示例

得益于整型距离值的设计，您可以非常方便地在自动化中使用数值条件。

### 示例 1：有人进入 3 米范围内时开灯

```yaml
alias: "雷达 - 近距离有人开灯"
trigger:
  - platform: numeric_state
    entity_id: sensor.hlk_ld2410d_b_target_distance
    below: 300    # 距离小于 300cm（3米）
    above: 0      # 排除配置模式(0)和无目标(2026)
action:
  - service: light.turn_on
    target:
      entity_id: light.living_room
```

### 示例 2：房间无人 5 分钟后关空调

```yaml
alias: "雷达 - 无人延时关空调"
trigger:
  - platform: numeric_state
    entity_id: sensor.hlk_ld2410d_b_target_distance
    above: 2000   # 大于 2000 即为无目标(2026)
    for:
      minutes: 5
action:
  - service: climate.turn_off
    target:
      entity_id: climate.bedroom_ac
```

### 示例 3：根据距离分级控制灯光亮度

```yaml
alias: "雷达 - 距离分级调光"
trigger:
  - platform: state
    entity_id: sensor.hlk_ld2410d_b_target_distance
action:
  - choose:
      - conditions:
          - condition: numeric_state
            entity_id: sensor.hlk_ld2410d_b_target_distance
            below: 150  # 1.5米内
        sequence:
          - service: light.turn_on
            data: { brightness_pct: 100 }
      - conditions:
          - condition: numeric_state
            entity_id: sensor.hlk_ld2410d_b_target_distance
            below: 400  # 4米内
        sequence:
          - service: light.turn_on
            data: { brightness_pct: 50 }
    default:
      - service: light.turn_on
        data: { brightness_pct: 10 }  # 远距离微亮
```

## 七、 常见问题与注意事项

### Q1：蓝牙连接不稳定或频繁断连？
- **蓝牙信号范围**：BLE 信号穿墙能力较弱，请确保 HA 主机与雷达模块之间距离不超过 5~8 米且无厚重墙体阻隔。
- **蓝牙适配器**：建议使用 CSR 4.0 以上的优质 USB 蓝牙适配器，避免使用劣质产品。
- **干扰**：远离 Wi-Fi 路由器、微波炉等 2.4GHz 频段干扰源。

### Q2：点击"重启"后诊断一直卡在某个进度？
- 重启流程设计为"发送指令后直接倒计时"，不依赖模块的 ACK 回复。
- 如果卡在 100% 之后未恢复正常模式，可能是蓝牙重连失败。请检查蓝牙适配器状态，或尝试手动点击"读取"按钮触发重连。

### Q3：目标距离一直显示 2026（无目标），但明明有人？
- **灵敏度太低**：尝试提高灵敏度（设为 3~5）并重新"设置"。
- **门限未生成**：在新环境中，建议先触发一次"自动门限生成"（修改门限系数后点击"设置"）。
- **安装角度**：确认雷达正面朝向检测区域，挂顶安装时注意正下方 0.5m 内存在盲区。

### Q4：配置模式下目标距离显示 0，会影响自动化吗？
- 在配置/重启模式下，距离值固定返回 `0`。
- 如果您的自动化条件中设置了 `above: 0`（如示例 1），则配置期间不会误触发，这是符合预期的安全设计。
